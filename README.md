# DIINormalization
Normalizing the DII algorithm for computer vision:
This repo will be used to conduct research to create a normalized Dietary Inflammatory Index(DII) algorithm using the publicly available SNAPme dataset.
The validated ingredient logs for each meal will be mapped to the 45 DII variables, and then images will be fed into latest computer vision models(ChatGPT, Gemini, etc.) to test how accurate computer vision can be at determining the dietary inflammatory index for a meal.
